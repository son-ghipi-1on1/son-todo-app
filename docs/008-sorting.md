# 008: 並び替え

## 概要

「期限が近い順」「作成が新しい順」を切り替えるUIを追加する。

## 関連要件

- F-07(並び替え)

## 依存

- 003

## 見積

0.5〜1時間

## タスク

- [ ] `app/components/SortSelect.tsx`(Client Component)を作成する
- [ ] 「期限が近い順」(デフォルト)・「作成が新しい順」の2択を実装する
- [ ] 選択に応じて一覧の取得クエリのソート条件を切り替える

| 選択肢 | ソート条件 |
| --- | --- |
| 期限が近い順(デフォルト) | `due_date ASC NULLS LAST, created_at DESC` |
| 作成が新しい順 | `created_at DESC` |

## 実装メモ

- 期限なしのタスクは常に末尾に配置する(`NULLS LAST`)。
- 手動ドラッグ&ドロップ並び替えはスコープ外(12章の将来拡張候補であり、`sort_order` 列とdnd-kitの導入が前提。今回は実装しない)。
- ソート状態はURLの検索パラメータ(`searchParams`)で保持するか、クライアント状態で保持するかは実装時に選択してよいが、`searchParams` を使う場合は必ず `await` すること(`CLAUDE.md` の破壊的変更セクション参照)。

## 完了条件

- デフォルトで「期限が近い順」が選択されている
- 「作成が新しい順」に切り替えると `created_at DESC` で並び替わる
- 「期限が近い順」で、期限なしのタスクが常に末尾に表示される
