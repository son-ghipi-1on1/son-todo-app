# 004: タスク作成フォーム

## 概要

タイトルと任意の期限日を指定して新規タスクを登録できるようにする。

## 関連要件

- F-01(タスク作成)

## 依存

- 003(一覧に追加したタスクが反映されることを確認するため)

## 見積

1〜1.5時間

## タスク

- [ ] `app/components/TodoForm.tsx`(Client Component)を作成する。入力欄・日付ピッカー・追加ボタン
- [ ] `app/actions.ts` に `createTodo` Server Actionを実装する
- [ ] タイトルが1〜200文字であること、空文字・空白のみではないことをServer Action側で検証する
- [ ] クライアント側でも同様のバリデーション(即時フィードバック用)を行う
- [ ] バリデーションエラーは `useActionState` で受け取り、フォーム上にエラーメッセージを表示する
- [ ] 登録成功後は入力欄をクリアし、続けて入力できる状態を維持する
- [ ] 登録後、一覧に反映される(`revalidatePath('/')`)

## 実装メモ

- バリデーションは**クライアント・サーバー双方**で行う。クライアント側のみの検証はServer Actionsへの直接POSTで迂回できるため、サーバー側の検証を省略しない(要件定義書 8.3節、`CLAUDE.md` の「Server Actions」節)。
- バリデーションエラーは「起こりうるエラー」なので `throw` せず戻り値としてモデル化し、`useActionState` の `state` からフォームに表示する(`CLAUDE.md` 参照)。
- 更新は `revalidatePath('/')` を使う方針(要件定義書 8.1節、`CLAUDE.md` の「キャッシュ更新」節)。

## 完了条件

- タイトルのみで登録でき、一覧の未完了タブに反映される
- タイトル+期限日で登録でき、期限日が一覧に表示される
- 空文字・空白のみでは登録できず、エラーメッセージが表示される
- 201文字以上のタイトルでは登録できず、エラーメッセージが表示される
- 登録後、入力欄がクリアされ続けて入力できる
