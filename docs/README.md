# Todoアプリ MVP チケット一覧

`CLAUDE.md` に記載した「Todoアプリ MVP 要件定義書」の内容を、実装順のチケットに分割したもの。各チケットの詳細な技術方針(データモデル・RLS・Server Actions・キャッシュ更新など)は `CLAUDE.md` を参照。

| # | チケット | 関連機能 | 見積 |
| --- | --- | --- | --- |
| [001](./001-supabase-setup.md) | Supabaseプロジェクト作成・テーブル/RLS設定 | データモデル・セキュリティ | 0.5〜1h |
| [002](./002-nextjs-project-setup.md) | Next.jsプロジェクト初期設定 | 技術スタック接続 | 0.5〜1h |
| [003](./003-todo-list-and-tabs.md) | 一覧表示・タブ切替 | F-02, F-08 | 1.5〜2h |
| [004](./004-task-create-form.md) | タスク作成フォーム | F-01 | 1〜1.5h |
| [005](./005-complete-toggle.md) | 完了トグル(楽観的更新) | F-03 | 1〜1.5h |
| [006](./006-inline-edit.md) | タスク編集(インライン編集) | F-04 | 1.5〜2h |
| [007](./007-delete-task.md) | タスク削除 | F-05 | 0.5h |
| [008](./008-sorting.md) | 並び替え | F-07 | 0.5〜1h |

合計見積: 8〜12時間(要件定義書 10章と同じ)

## 実装順序

001 → 002 は前提条件。003(一覧表示)は他の全機能の土台となるため、004〜008より先に実装する。003完了後は004〜008を任意の順で進められる(それぞれ003にのみ依存)。009は表示系機能が揃った後の仕上げ、010は最後のデプロイ。

## スコープ外

要件定義書 9章の通り、以下はチケット化していない: ユーザー認証・アカウント管理、タグ/カテゴリ、検索・フィルタ、ドラッグ&ドロップ並び替え、サブタスク、繰り返しタスク、リマインダー・通知、複数端末同期、削除の取り消し・ゴミ箱、ダークモード、インポート/エクスポート。
