# 007: タスク削除

## 概要

行のホバー時に表示される削除ボタンから、確認ダイアログなしで即時にタスクを物理削除する。

## 関連要件

- F-05(タスク削除)

## 依存

- 003

## 見積

0.5時間

## タスク

- [ ] `app/actions.ts` に `deleteTodo` Server Actionを実装する(idのみ受け取り物理削除)
- [ ] `TodoItem.tsx` にホバー時のみ表示される削除ボタンを実装する
- [ ] クリックで確認ダイアログを出さず即時削除する
- [ ] 削除後、一覧に反映される(`revalidatePath('/')`)
- [ ] キーボードのみでも削除ボタンにフォーカス・実行できるようにする(ホバー専用にしない)

## 実装メモ

- MVPでは復元・ゴミ箱機能は提供しない(物理削除のみ)。要件定義書 11章のリスク一覧にある通り、この制約は意図的なもの。
- 「ホバー時に表示」はマウス操作の話であり、キーボードユーザーのために `:focus-within` 等でも表示されるようにする(4章のアクセシビリティ要件)。

## 完了条件

- 行にマウスを乗せると削除ボタンが表示される
- クリックすると確認なしで即座に削除され、一覧から消える
- キーボード操作(Tab等)でも削除ボタンにフォーカスして実行できる
