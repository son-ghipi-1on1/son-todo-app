# 006: タスク編集(インライン編集)

## 概要

タイトルをクリックするとインライン編集モードに切り替わり、タイトルと期限日を変更できるようにする。

## 関連要件

- F-04(タスク編集)

## 依存

- 003

## 見積

1.5〜2時間(工数が膨らみやすい箇所。重い場合はモーダル方式への切り替えを検討する — 要件定義書 6章末尾)

## タスク

- [ ] `app/actions.ts` に `updateTodo` Server Actionを実装する(id・title・due_dateを受け取る)
- [ ] `TodoItem.tsx`(Client Component)でタイトルクリック時にインライン編集モードへ切り替える
- [ ] Enterキーで確定、Escapeキーでキャンセル、フォーカスが外れたら確定する
- [ ] 期限日を日付ピッカーで変更できる。クリアして未設定にもできる
- [ ] タイトルのバリデーション(1〜200文字、空白のみ不可)をServer Action側で行う
- [ ] 更新後、一覧に反映される(`revalidatePath('/')`)

## 実装メモ

- キーボード操作(Enter/Escape/blur)はアクセシビリティ要件(4章)でもあり、マウスなしで完結できることが必須。
- バリデーションは004と同様、Server Action側で必ず行う。
- 見積が膨らみやすいと要件定義書に明記されている箇所。インライン編集の実装コストが高い場合は、モーダル方式への切り替えを検討してよい(その場合は本チケットの実装メモを更新すること)。

## 完了条件

- タイトルをクリックするとインライン編集モードになり、テキスト入力できる
- Enterで確定して一覧に反映される
- Escapeでキャンセルすると変更が破棄される
- 編集中に他の場所をクリック(blur)すると確定される
- 期限日を日付ピッカーで変更・クリアできる
- 空白のみのタイトルには更新できない
