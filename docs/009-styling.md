# 009: スタイリング調整

## 概要

期限日の視覚表現・レスポンシブ対応・アクセシビリティなど、非機能要件を満たすスタイリングを仕上げる。

## 関連要件

- 4章(非機能要件)
- 7.2節(期限日の視覚表現)

## 依存

- 003〜008(表示対象の機能が一通り揃っていること)

## 見積

1〜2時間

## タスク

- [ ] 期限日の色分けを実装する

| 状態 | 表示 |
| --- | --- |
| 期限切れ | 赤色 + 警告アイコン |
| 本日が期限 | オレンジ色 |
| 3日以内 | 通常色(太字) |
| それ以降 | 通常色 |
| 期限なし | グレーで「期限なし」 |

- [ ] 375px(スマートフォン)からデスクトップまでのレスポンシブ対応を確認・調整する
- [ ] キーボード操作のみでタスクの追加・完了・削除が一通り完結することを確認する(4章)
- [ ] Tailwind CSSでスタイリングし、UIライブラリの追加は最小限に留める

## 実装メモ

- 日付の状態判定(期限切れ/本日/3日以内/それ以降)はタイムゾーンに注意する。`due_date` は `date` 型で時刻を持たないため、比較はサーバーのタイムゾーンに依存させず、ローカル日付同士で比較するロジックにする。
- 本MVPではダークモード対応はスコープ外(11章の将来拡張候補にも入っていない)。

## 完了条件

- 期限切れ・本日・3日以内・それ以降・期限なしの5パターンが仕様通りの色/装飾で表示される
- 375px幅でもレイアウトが崩れず操作できる
- Tabキーのみでタスクの追加・完了トグル・削除まで一通り操作できる
