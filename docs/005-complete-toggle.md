# 005: 完了トグル(楽観的更新)

## 概要

チェックボックスのクリックで、サーバー応答を待たずに完了/未完了を即座に切り替える。

## 関連要件

- F-03(完了トグル)

## 依存

- 003

## 見積

1〜1.5時間

## タスク

- [ ] `app/actions.ts` に `toggleTodo` Server Actionを実装する(対象IDと現在の状態、または反転後の状態を受け取る)
- [ ] `TodoItem.tsx` のチェックボックスクリックで `useOptimistic` を使い、サーバー応答を待たずUIを先に更新する
- [ ] 完了にすると即座に未完了タブから消え、完了済みタブに移動する(表示上)
- [ ] サーバー確定後、実データで整合させる(`revalidatePath('/')`)
- [ ] サーバー側で失敗した場合、楽観的更新をロールバックする

## 実装メモ

- 完了トグルは要件定義書・`CLAUDE.md` ともに「`useOptimistic` を使う唯一の操作」と明記されている。他の操作(作成・編集・削除)は楽観的更新にしない。
- `toggleTodo` はクライアントから対象のIDのみを受け取り、他のカラム(`title` や `due_date`)をクライアントの入力からそのまま上書きしない(`CLAUDE.md` の「Server Actions」節)。

## 完了条件

- チェックボックスをクリックすると、通信を待たずに即座に見た目が完了状態になる
- 完了にしたタスクが未完了タブから消え、完了済みタブに現れる(逆も同様)
- ネットワークを意図的に遅延/失敗させても、UIが極端に破綻しない(失敗時はロールバックされる)
