# 010: Vercelデプロイ・動作確認

## 概要

Vercelへデプロイし、公開URLで一通りの機能が動作することを確認する。

## 関連要件

- 2章(技術スタック: ホスティング = Vercel、GitHub連携による自動デプロイ)

## 依存

- 001〜009すべて

## 見積

0.5〜1時間

## タスク

- [ ] GitHubリポジトリと連携し、Vercelプロジェクトを作成する
- [ ] Vercelの環境変数に `NEXT_PUBLIC_SUPABASE_URL` / `NEXT_PUBLIC_SUPABASE_ANON_KEY` を設定する
- [ ] デプロイ後、公開URLでF-01〜F-08の一連の動作を確認する
- [ ] 初回表示が3秒以内であることを確認する(4章)

## 実装メモ

- **重要**: 公開URLになった時点で、URLを知る第三者は誰でもタスクを閲覧・作成・編集・削除できる(RLSを `anon` に全開放しているため)。機密情報をタスクに登録しないことを、実運用開始前に改めて認識しておくこと(`CLAUDE.md` の「セキュリティ」節、要件定義書 6.3節)。
- Supabase無料プランは一定期間アクセスがないとプロジェクトが一時停止する。デプロイ後に長期間放置しないこと(要件定義書 11章)。

## 完了条件

- 公開URLからF-01〜F-08すべての機能が一通り動作する
- Vercelダッシュボード上でビルド・デプロイが成功している
- 初回表示が体感3秒以内である
